# Sales_Analysis_Project-Excel-Power-BI-SQL-Tableau
Executed an end-to-end data analysis project using Excel, Power BI, SQL, and Tableau to generate actionable insights, identify trends, and enable data-driven strategic decisions.

Project Overview 

The project analyzed sales data to assess overall business performance and support data-driven decision-making. 
Key activities included:

- Data Cleaning & Transformation: Ensured accuracy and consistency of raw data using SQL and Excel.

- Data Modeling: Designed a star schema with Sales as the fact table and Date, Customer, Product, and Sales Territory as dimension tables.

- Data Analysis & Visualization: Developed interactive dashboards and reports using Power BI and Tableau to highlight trends and performance metrics.

- Business Insights: Extracted actionable insights and recommendations based on patterns and trends in sales data.
